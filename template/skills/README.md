# Skills / Prompts / Agent configs

วาง Claude Skills (`<skill-name>/SKILL.md`), prompt templates และ agent configs ไว้ในโฟลเดอร์นี้

ข้อกำหนด:
- ทุก skill ต้องมีคำอธิบายว่าใช้ทำอะไร และใช้ tool/สิทธิ์อะไรบ้าง
- ห้ามมีคำสั่งที่ส่งข้อมูลออกนอกองค์กร อ่าน credential หรือดาวน์โหลดแล้วรันสคริปต์จากภายนอก
- workflow `vibe-audit` จะสแกนโฟลเดอร์นี้อัตโนมัติ
