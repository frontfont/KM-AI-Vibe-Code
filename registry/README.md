# Registry

`projects.yaml` คือรายชื่อผลงานที่ผ่าน Audit แล้ว เว็บ Hub อ่านไฟล์นี้ แล้วดึง `kabac.yaml` ของแต่ละ repo มาแสดงเป็น Canvas และ Badge

ขั้นตอนเพิ่มผลงาน:
1. ผู้ส่งเปิด Issue "🚀 ส่งผลงาน Vibe Coding"
2. ผู้ตรวจตาม Tier ตรวจตาม [AUDIT-CHECKLIST.md](../docs/AUDIT-CHECKLIST.md) ใน Issue นั้น
3. AI CoE เปิด PR เพิ่มรายการลง `projects.yaml` แล้วอ้างอิง Issue
